Forecasts GTA VI's launch-day (2026-11-19 UTC) Twitch concurrent viewers in the "Grand Theft Auto VI" category, hours 2–24, as five quantiles per hour. It learns the launch-day curve from the kit's past launches at run time: per-hour log-ratio regressions on hour-1 viewers over rolling-midnight launches only, with residual-based spreads.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
